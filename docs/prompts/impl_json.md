serde使用

json の Serialize, Deserialize を する関数を実装．

Serialize, Deserialize を するためのサンプル構造体を定義．

サンプル構造体は入れ子構造や， null や 配列， いろいろな型を 含むようにする．

ドメインで使用する構造体は Optionなど使わずをデフォルトで埋める.

サンプル構造体からドメインで使用する構造体の変換を実装する．

値の validateや nullをデフォルトで埋める処理をする．
